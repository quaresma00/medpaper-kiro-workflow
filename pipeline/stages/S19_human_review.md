# S19 - Review rounds on the complete paper, then the user's release

Goal: improve the paper in subagent review rounds, report each round once, stop when the
user confirms with the exact sentence 我确认这一版, then freeze the science.
Details (fixing rules, rework routing, preview/confirm-rewind): `reference/stage_details/S19_human_review.md`.

## One round
1. Review. Round 1 is the S18 review; later rounds (also while the previous one awaits the
   user):
```
.\.venv\Scripts\python.exe tools/review_round.py start --delta
```
   Give the `medpaper-reviewer` agent only the printed bundle path and brief; it writes its
   report to `.wf/review_bundle/<round>/report.md`.
2. Fix on your own judgement. Batch ALL analysis edits of the round into one plan, re-run the
   chain once and reproduce once (`.\.venv\Scripts\python.exe tools/reproduce.py run --wait`).
   Prose rewrites go to the `medpaper-clinical-writer` agent:
```
.\.venv\Scripts\python.exe tools/manuscript/writer_bundle.py build --stage S19_human_review --target 07_manuscript/<section>.md
.\.venv\Scripts\python.exe tools/manuscript/assemble.py --check
```
   Edit owning sources only, rebuild dependants. Science frozen or a rework round open ->
   `tools/rework.py` (`preview` first; an S19 return needs the user's 我确认回退): after the
   freeze only changed analysis/data/results, a changed reported value or an untraceable new
   number is science; traceable new numbers, deletions and reviewer wording are presentation.
   No multi-person coding for automated extraction, no protocol-deviation text.
3. Close against the saved report (default: the bundle's report.md), every F-numbered finding
   once: numbers/grouping/conclusion_strength fixed by default (`changed`), or `author` +
   `--recommend <id> keep`; `other` findings are yours; OPTIONAL lines: one group
   (`--preference-group "<why>"`):
```
.\.venv\Scripts\python.exe tools/review_round.py close --findings critical=<n>,major=<n>,minor=<n> --finding <id> <category> <status> "<one line>" --change <file> "<one line>" --kept "<id>" "<why>"
```
   Author answers: `review_round.py author <id> change|keep --words-file <utf-8 file>`;
   "按你的建议" = `review_round.py author all --words "按你的建议"`.
4. ONE message to the user: findings by severity, changes (file + one line), what was kept
   and why, paths, and the block `close` prints unchanged (sentence, preconditions, pending
   items with your recommendation; 1.26.0: the basic author facts, AI use and the portal
   question not yet in `wf decisions show` - answer now or later). End with:
   > 本轮审阅与修改已完成。需要再审一轮请直接说明；确认当前版本请回复：我确认这一版
   Also valid: 确认 + 这一版/此版/本版/这个版本, or "I confirm this version".
5. Record the answer (Chinese words: prefer `--words-file`; mojibake is refused); facts the
   user gives: `wf decisions set authors|funding|conflicts|ai_use|portal_check <value> --words`:
```
.\.venv\Scripts\python.exe tools/review_round.py decide another_round --words "<user's words>"
.\.venv\Scripts\python.exe tools/review_round.py decide no_further_review --words "我确认这一版"
```

## Freeze the science
```
.\.venv\Scripts\python.exe tools/manuscript/scientific_freeze.py capture
```
`07_manuscript/` is read-only from here; journal edits go to `08_submission/manuscript/`.
Paragraphs changed in a round go to the medical editor, only those
(`writer_bundle.py edit --section manuscript`; `--section S` for a source section).

## Outputs
- `07_manuscript/human_review.md` (generated by `review_round.py`)
- `07_manuscript/scientific_freeze.json`

## Gate
review round approved and bound to the latest round, findings closed, explicit
confirmation, revision rounds closed, freeze captured (non-overridable). Author facts only
inside that one message, never a separate pause. Export copies only on request.

## Close
```
.\.venv\Scripts\python.exe tools/wf.py check
.\.venv\Scripts\python.exe tools/wf.py advance --note "review rounds=<n>; last=<round id>; user: no further review; freeze captured"
```
